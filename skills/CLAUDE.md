# Skills Directory

When editing skills, follow these conventions:
- SKILL.md is procedure (steps, decision trees) — keep under 200 lines
- references/ is lookup data (tables, scripts, templates)
- description must be 100-1024 chars, start with "Use when..."
- Every skill needs: When to use, When NOT to use, Steps, Related skills
- Metric names must be verified — never invent a metric name
